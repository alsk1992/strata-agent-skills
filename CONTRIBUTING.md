# Contributing

Keep each skill concise, capability-driven, portable, and safe for untrusted
agent contexts. Put detailed semantics in a directly linked reference file.

Do not add private service names, infrastructure details, routing composition,
credentials, wallet handling, or undocumented interfaces. The Strata skill must
never teach an agent to prepare, sign, or submit a transaction until the public
contract explicitly supports that capability.

Validate every changed skill before requesting review.
